# qual-research-simulator has moved

This plugin now lives in **[P4-Product-Design/claude-plugins](https://github.com/P4-Product-Design/claude-plugins/tree/main/plugins/qual-research-simulator)**, the one marketplace for every P4 plugin. This repo is archived and won't get updates.

## Switch over

1. In Claude Desktop, open **Customize → Manage plugins**. Remove `qual-research-simulator` and its `qual-research-simulator` marketplace.
2. Click **+** → **Add** → **Add marketplace**, paste `P4-Product-Design/claude-plugins`, and click **Sync**.
3. Click **Plugins**, open the **p4-product-design** tab, and click **+** on `qual-research-simulator`.

Full instructions are in the [claude-plugins README](https://github.com/P4-Product-Design/claude-plugins#readme).
